# IntelliCockpitBench Data Access Request Draft

Use this draft to request the full IntelliCockpitBench dataset from the maintainers if no public download link is available.

## Subject

Request for academic access to the full IntelliCockpitBench dataset

## Message

Dear IntelliCockpitBench authors,

I am working on DriveMind-VL, a research engineering project on multimodal in-vehicle agents based on Qwen2.5-VL. We are evaluating cockpit and driving-scene visual grounding, safety-aware responses, and multimodal VQA reliability.

We found your IntelliCockpitBench project and would like to use it as our primary public benchmark for intelligent-cockpit VQA. The GitHub repository currently appears to include a small sample under `Evaluation/data/jsonl/english_test.jsonl` and several example images. Could you please let us know whether the full benchmark package is available for academic use?

The package we need is:

- full English and/or Chinese test JSONL metadata;
- corresponding image directory;
- any official split files;
- license or usage terms;
- recommended evaluation protocol and scoring scripts.

We will not redistribute the original images or raw benchmark files. We plan to report results only as aggregate metrics and qualitative error analysis, with citation to your paper and repository.

Thank you for your work.

Best regards,

DriveMind-VL project team
